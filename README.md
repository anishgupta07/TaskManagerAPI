# 📝 Task Manager API (Spring Boot)

## 🚀 Tech Stack

* Java
* Spring Boot
* Spring Data JPA
* MySQL
* ModelMapper

---

## 📌 Features

* Create Task
* Update Task
* Delete Task
* Get All Tasks
* Exception Handling
* DTO Mapping
* Clean API Response

---

## 🏗️ Architecture

Controller → Service → Repository → Database

---

## 🔗 API Endpoints

### 1. Create Task

POST /tasks

### 2. Get All Tasks

GET /tasks

### 3. Update Task

PUT /tasks/{id}

### 4. Delete Task

DELETE /tasks/{id}

---

## ⚙️ How to Run

1. Clone repo
2. Create MySQL DB: task_manager
3. Update application.properties
4. Run Spring Boot app

---

* Layered Architecture
